# Voyage · Modern AI Trip Planner & Itinerary

Voyage is a modern, self-hosted web application for planning, viewing, and sharing trips.

## Features
- **Planning Mode:** Start with a destination, dates, travelers, and travel style. Get tailored ideas, attractions, restaurants, and hotels using Google Gemini (gemini-3.8-flash) or local Ollama, enhanced with real-time web search.
- **Viewing Mode:** Clean, at-a-glance day-by-day itinerary with time blocks, interactive OpenStreetMap routes, and **one-click Google Maps directions**.
- **Inline Editing:** Tweak times, notes, and details directly from the viewing itinerary.
- **Tools Included:** Categorized packing checklist with AI auto-generator and a multi-currency budget & expense tracker.
- **Sharing:** Secret read-only guest links for phones, plus one-click standalone offline HTML guide and Apple/Google Calendar (.ics) export.
